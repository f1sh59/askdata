## 7. 失败明细

### h03 · hard · 列数不一致

- 问题：2025 年每个月的累计销售额是多少？
- 口径：累计值 = 年初到当月的销售额

```sql
-- gold
WITH m AS (SELECT strftime(order_time, '%Y-%m') AS ym, SUM(pay_amount) AS amt FROM orders WHERE status IN ('已支付', '已发货', '已完成') AND order_time >= TIMESTAMP '2025-01-01' AND order_time < TIMESTAMP '2026-01-01' GROUP BY ym) SELECT ym, ROUND(SUM(amt) OVER (ORDER BY ym), 2) AS cum_amt FROM m ORDER BY ym

-- generated
SELECT
    strftime(order_time, '%Y-%m') AS month,
    SUM(pay_amount) AS monthly_sales,
    SUM(SUM(pay_amount)) OVER (ORDER BY strftime(order_time, '%Y-%m')) AS cumulative_sales
FROM orders
WHERE status IN ('已支付', '已发货', '已完成')
  AND order_time >= TIMESTAMP '2025-01-01'
  AND order_time < TIMESTAMP '2026-01-01'
GROUP BY strftime(order_time, '%Y-%m')
ORDER BY month
```

### h05 · hard · 结果值不一致

- 问题：2025 年的订单中，用户相邻两次有效下单之间间隔天数的中位数是多少？
- 口径：同用户同日多单的间隔为 0；中位数按天算

```sql
-- gold
WITH o AS (SELECT user_id, order_time, LAG(order_time) OVER (PARTITION BY user_id ORDER BY order_time) AS prev_time FROM orders WHERE status IN ('已支付', '已发货', '已完成')) SELECT ROUND(percentile_cont(0.5) WITHIN GROUP (ORDER BY date_diff('day', prev_time, order_time)), 1) AS median_gap_days FROM o WHERE prev_time IS NOT NULL AND order_time >= TIMESTAMP '2025-01-01' AND order_time < TIMESTAMP '2026-01-01'

-- generated
WITH valid_orders AS (
    SELECT
        user_id,
        order_time,
        LAG(order_time) OVER (PARTITION BY user_id ORDER BY order_time) AS prev_order_time
    FROM orders
    WHERE status IN ('已支付', '已发货', '已完成')
      AND order_time >= TIMESTAMP '2025-01-01'
      AND order_time < TIMESTAMP '2026-01-01'
),
intervals AS (
    SELECT
        user_id,
        date_diff('day', prev_order_time, order_time) AS gap_days
    FROM valid_orders
    WHERE prev_order_time IS NOT NULL
)
SELECT
    median(gap_days) AS median_gap_days
FROM intervals
```

### h07 · hard · 结果值不一致

- 问题：2025 年下过单、但在 2025 年的订单里一次都没有支付成功的用户有多少个？
- 口径：判定范围是 2025 年的订单：该用户 2025 年所有订单都没有成功支付记录；历史订单不看

```sql
-- gold
SELECT COUNT(*) AS user_cnt FROM (SELECT o.user_id FROM orders o LEFT JOIN payments p ON p.order_id = o.order_id AND p.pay_status = '成功' WHERE o.order_time >= TIMESTAMP '2025-01-01' AND o.order_time < TIMESTAMP '2026-01-01' GROUP BY o.user_id HAVING COUNT(p.payment_id) = 0) t

-- generated
SELECT COUNT(DISTINCT o.user_id) AS user_count
FROM orders o
WHERE o.order_time >= TIMESTAMP '2025-01-01'
  AND o.order_time < TIMESTAMP '2026-01-01'
  AND NOT EXISTS (
    SELECT 1
    FROM payments p
    WHERE p.order_id = o.order_id
      AND p.pay_status = '成功'
  )
```

### h08 · hard · SQL 执行失败

- 问题：2025 年每个月的复购用户数是多少？（当月有效订单不少于 2 笔的用户）
- 口径：按月判断复购，不是全年的复购用户
- 报错：`BinderException: Binder Error: Referenced column "order_time" not found in FROM clause! Candidate bindings: "order_cnt", "order_month", "user_id" LINE 16: GROUP BY strftime(order_time, '%Y-%m') ^^^^^^^^^^`

```sql
-- gold
WITH m AS (SELECT strftime(order_time, '%Y-%m') AS ym, user_id, COUNT(*) AS c FROM orders WHERE status IN ('已支付', '已发货', '已完成') AND order_time >= TIMESTAMP '2025-01-01' AND order_time < TIMESTAMP '2026-01-01' GROUP BY ym, user_id) SELECT ym, COUNT(*) AS repeat_user_cnt FROM m WHERE c >= 2 GROUP BY ym ORDER BY ym

-- generated
SELECT
    strftime(order_time, '%Y-%m') AS month,
    COUNT(*) AS repeat_users
FROM (
    SELECT
        user_id,
        strftime(order_time, '%Y-%m') AS order_month,
        COUNT(*) AS order_cnt
    FROM orders
    WHERE status IN ('已支付', '已发货', '已完成')
      AND order_time >= TIMESTAMP '2025-01-01'
      AND order_time < TIMESTAMP '2026-01-01'
    GROUP BY user_id, strftime(order_time, '%Y-%m')
    HAVING COUNT(*) >= 2
) t
GROUP BY strftime(order_time, '%Y-%m')

```
