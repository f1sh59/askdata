## 7. 失败明细

### m13 · medium · 结果值不一致

- 问题：2025 年各渠道的销售额、退款金额和退款率分别是多少？（退款率 = 已完成退款金额 / 销售额 × 100，返回四列：渠道、销售额、退款金额、退款率）
- 口径：退款额按退款时间归 2025；没有退款的渠道要补 0（LEFT JOIN）

```sql
-- gold
WITH gmv AS ( SELECT channel_id, SUM(pay_amount) AS amt FROM orders WHERE status IN ('已支付', '已发货', '已完成') AND order_time >= TIMESTAMP '2025-01-01' AND order_time < TIMESTAMP '2026-01-01' GROUP BY channel_id ), rf AS ( SELECT o.channel_id, SUM(r.refund_amount) AS amt FROM refunds r JOIN orders o ON o.order_id = r.order_id WHERE r.status = '已完成' AND r.refund_time >= TIMESTAMP '2025-01-01' AND refund_time < TIMESTAMP '2026-01-01' GROUP BY o.channel_id ) SELECT c.channel_name, ROUND(g.amt, 2), ROUND(COALESCE(rf.amt, 0), 2), ROUND(COALESCE(rf.amt, 0) / g.amt * 100, 2) FROM gmv g JOIN channels c ON c.channel_id = g.channel_id LEFT JOIN rf ON rf.channel_id = g.channel_id ORDER BY 2 DESC

-- generated
SELECT
    c.channel_name AS 渠道,
    COALESCE(o.sales_amount, 0) AS 销售额,
    COALESCE(r.refund_amount, 0) AS 退款金额,
    CASE WHEN COALESCE(o.sales_amount, 0) = 0 THEN NULL
         ELSE COALESCE(r.refund_amount, 0) / o.sales_amount * 100
    END AS 退款率
FROM channels c
LEFT JOIN (
    SELECT channel_id, SUM(pay_amount) AS sales_amount
    FROM orders
    WHERE status IN ('已支付', '已发货', '已完成')
      AND order_time >= TIMESTAMP '2025-01-01'
      AND order_time < TIMESTAMP '2026-01-01'
    GROUP BY channel_id
) o ON c.channel_id = o.channel_id
LEFT JOIN (
    SELECT o2.channel_id, SUM(rf.refund_amount) AS refund_amount
    FROM refunds rf
    JOIN orders o2 ON rf.order_id = o2.order_id
    WHERE rf.status = '已完成'
      AND o2.order_time >= TIMESTAMP '2025-01-01'
      AND o2.order_time < TIMESTAMP '2026-01-01'
    GROUP BY o2.channel_id
) r ON c.channel_id = r.channel_id
ORDER BY c.channel_id
```
