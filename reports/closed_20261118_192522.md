## 3. 澄清后仍然失败的题

### v07 · 结果值不一致

- 原问题：各会员等级表现如何？
- 用户补充：2025 年，每个会员等级的销售额和订单数，等级缺失的算「未知」。

```sql
-- gold
SELECT COALESCE(u.member_level, '未知'), ROUND(SUM(o.pay_amount), 2) AS amt, COUNT(*) AS order_cnt FROM orders o JOIN users u ON u.user_id = o.user_id WHERE o.status IN ('已支付','已发货','已完成') AND o.order_time >= TIMESTAMP '2025-01-01' AND order_time < TIMESTAMP '2026-01-01' GROUP BY 1 ORDER BY amt DESC

-- generated
SELECT
    COALESCE(u.member_level, '未知') AS member_level,
    SUM(oi.item_amount) AS sales_amount,
    COUNT(DISTINCT o.order_id) AS order_count
FROM orders o
JOIN order_items oi ON o.order_id = oi.order_id
LEFT JOIN users u ON o.user_id = u.user_id
WHERE o.status IN ('已支付', '已发货', '已完成')
  AND o.order_time >= TIMESTAMP '2025-01-01'
  AND o.order_time < TIMESTAMP '2026-01-01'
GROUP BY COALESCE(u.member_level, '未知')
ORDER BY sales_amount DESC
```

### v08 · 结果值不一致

- 原问题：同比表现怎么样？
- 用户补充：看销售额，2025 年对比 2024 年的同比增长率，只要给我增长率这一个百分比数值。

```sql
-- gold
WITH a AS (SELECT SUM(pay_amount) AS amt FROM orders WHERE status IN ('已支付','已发货','已完成') AND order_time >= TIMESTAMP '2025-01-01' AND order_time < TIMESTAMP '2026-01-01'), b AS (SELECT SUM(pay_amount) AS amt FROM orders WHERE status IN ('已支付','已发货','已完成') AND order_time >= TIMESTAMP '2024-01-01' AND order_time < TIMESTAMP '2025-01-01') SELECT ROUND((a.amt - b.amt) / b.amt * 100, 2) FROM a, b

-- generated
WITH yearly_sales AS (
    SELECT
        CASE
            WHEN o.order_time >= TIMESTAMP '2025-01-01' AND o.order_time < TIMESTAMP '2026-01-01' THEN 2025
            WHEN o.order_time >= TIMESTAMP '2024-01-01' AND o.order_time < TIMESTAMP '2025-01-01' THEN 2024
        END AS year,
        SUM(oi.item_amount) AS sales_amount
    FROM orders o
    JOIN order_items oi ON o.order_id = oi.order_id
    WHERE o.status IN ('已支付', '已发货', '已完成')
      AND (
          (o.order_time >= TIMESTAMP '2025-01-01' AND o.order_time < TIMESTAMP '2026-01-01')
          OR (o.order_time >= TIMESTAMP '2024-01-01' AND o.order_time < TIMESTAMP '2025-01-01')
      )
    GROUP BY 1
)
SELECT
    (MAX(CASE WHEN year = 2025 THEN sales_amount END) - MAX(CASE WHEN year = 2024 THEN sales_amount END))
    / MAX(CASE WHEN year = 2024 THEN sales_amount END) * 100 AS yoy_growth_rate
FROM yearly_sales
```
